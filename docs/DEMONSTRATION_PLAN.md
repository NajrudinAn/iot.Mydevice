# Demonstration Plan

The final college demonstration should take only a few minutes, following these steps:

1. **STEP 1:** Open the web platform dashboard.
2. **STEP 2:** Login (or register a new user).
3. **STEP 3:** Add a new IoT device in the dashboard.
4. **STEP 4:** Show the generated Device ID and Secret Key on screen.
5. **STEP 5:** Configure these exact credentials in the ESP32 connector code (and upload).
6. **STEP 6:** Power on the ESP32.
7. **STEP 7:** Show the device status becoming "ONLINE" on the dashboard.
8. **STEP 8:** Show the physical DHT sensor and explain the telemetry being published.
9. **STEP 9:** Show the live temperature/humidity data appearing on the dashboard.
10. **STEP 10:** Turn the LED "ON" by clicking a button on the dashboard.
11. **STEP 11:** Show the physical LED turning ON.
12. **STEP 12:** Turn the LED "OFF" on the dashboard.
13. **STEP 13:** Show the physical LED turning OFF.

# Project Requirements

## Functional Requirements
- **FR-01** User registration
- **FR-02** User login
- **FR-03** Add device
- **FR-04** Generate Device ID
- **FR-05** Generate Secret Key
- **FR-06** List devices
- **FR-07** Device authentication
- **FR-08** MQTT telemetry
- **FR-09** Sensor data storage
- **FR-10** Device status
- **FR-11** REST API
- **FR-12** Dashboard monitoring
- **FR-13** Remote command
- **FR-14** LED control
- **FR-15** Connector-based device integration

## Non-Functional Requirements
- **NFR-01** Simplicity
- **NFR-02** Low cost
- **NFR-03** Maintainability
- **NFR-04** Basic security
- **NFR-05** Understandability
- **NFR-06** Reusability
